# App-pruebas

Este repositorio incluye una hoja de estilos base para una interfaz tipo dashboard.

## Contenido

- `styles.css`: estilos globales, layout responsive, paneles, formularios, tabla, gráfico y utilidades de accesibilidad.

## Uso rápido

1. Crea (o usa) un archivo HTML.
2. Enlaza la hoja de estilos en el `<head>`:

```html
<link rel="stylesheet" href="./styles.css" />
```

3. Define las variables CSS que usa el tema (`--bg`, `--text`, `--muted`, etc.) antes de cargar componentes.

## Descarga

- Enlace de descarga del archivo: [Descargar `styles.css`](./styles.css).

## Nota

La hoja de estilos usa variables CSS (`var(--...)`) para permitir tematización. Si no se definen en tu app, algunos colores/fuentes no se verán como esperas.
